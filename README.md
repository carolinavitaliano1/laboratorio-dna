# Laboratório do DNA

Simulações interativas de biologia molecular em português, para estudar mexendo.

- Estrutura do núcleo
- Formação da cadeia de nucleotídeos
- Replicação do DNA
- Transcrição e processamento do RNA
- Tradução
- Epigenética e controle dos genes
- Estrutura do gene: procarionte e eucarionte

É um site estático: tudo está em `index.html`, sem etapa de build.
